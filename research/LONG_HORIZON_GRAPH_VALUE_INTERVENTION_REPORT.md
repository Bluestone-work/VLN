# Long-horizon Graph Value Intervention

Date: 2026-10-09

No new online intervention was started. The pilot passed infrastructure checks
but not the scientific prerequisite for intervention: a frozen scene-disjoint
offline gate with stable improvement over native graph logits and controlled
harmful replacements.

Existing privileged/native-continuation evidence remains mixed. The route-
disjoint study rescued 3/7 native failures in its critical census and changed
27/96 routes in the frozen scorer arm, with 3 rescues and 0 native-success
losses; however, 13 treated routes lost nDTW, 10 lost SPL and 12 used more
primitive actions. The subsequent prospective replication failed the registered
primitive-cost gate. These are not deployable gains and do not justify running
the intervention again on the same or inspected routes.

Current intervention decision: **NO-GO / deferred**. Preserve native ETPNav as
the only executed policy until a new scene-disjoint offline dataset passes the
protocol gates. Any future intervention must use a critical-state margin gate,
retain every changed action and report beneficial, neutral and harmful paired
outcomes plus scene/route confidence intervals.
